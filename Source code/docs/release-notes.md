# Windows Traige v2.0

This portable build includes the Windows Traige desktop workbench and WindowsTraige.Cli.exe. Extract the entire archive. Keep both executables alongside the _internal and _cli_runtime folders. Use WindowsTraige.Cli.exe --help for command arguments.

The desktop offers System, Light and Dark appearance, plain-language evidence and raw JSON, and a separate offline Evidence Summary. Extended collection includes additional Windows operational logs and system metadata. The assistant offers named models, manual IDs, a local key file picker, chat with follow-ups and approval for case actions.

The collection page offers five optional sources in the same ZIP. Add a raw disk image, a saved memory capture, a Defender XDR DeviceEvents CSV, an Entra sign-in JSON export, or a saved PCAP or PCAPNG. The offline imaging guide records operator-reported write protection and acquisition details for a raw image prepared with an approved tool.

For an existing saved file, **Set up** requires only the file. **Show optional details** explains how to record the source, tool, operator, time, handoff notes and a separately supplied checksum.

Supplemental originals use ZIP64 when large-file support is needed. The case accepts v1.0 ZIPs, v2.0 ZIPs and saved EVTX. Coverage lists original hashes and source gaps. Use **Save original** in the timeline to make a verified working copy.

Evidence and case operations are local. The assistant starts disabled and uses a provider only after the operator enables it and initiates a provider action. Keep case material in an authorized private destination. See the build verification record for tested Windows builds and open acceptance checks.
